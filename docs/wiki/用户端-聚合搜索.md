# 用户端 - 聚合搜索

> 对应源码：`web/src/pages/SearchResultsPage.tsx`  
> 路由：`/search?q=关键词`

## 页面概览

聚合搜索页面提供全站统一搜索入口，基于 Elasticsearch 实现跨内容类型的全文检索，覆盖书籍、章节、帖子等多种资源。

---

### 核心功能

- **搜索类型 Tab 切换**：
  - **全部**：聚合所有类型的搜索结果
  - **书籍**：搜索电子书（展示封面、标题、作者、文件类型标签）
  - **章节**：搜索书籍章节内容
  - **帖子**：搜索社区帖子
- **关键词高亮**：搜索结果中的匹配关键词以品牌色高亮显示（`<em>` 标签渲染）
- **热搜推荐**：页面提供热搜词标签（斗破苍穹、编程入门、数学、英语、科学实验等）
- **分页浏览**：每页 20 条结果，支持前后翻页
- **文件类型色彩标识**：PDF（玫红）、EPUB（紫色）、TXT（天蓝）、DOCX（蓝色）

## 技术要点

- **Elasticsearch 集成**：后端使用 ES 进行全文检索，返回 `SearchResultDTO` 包含高亮片段
- **高亮渲染**：`HighlightText` 组件通过 `dangerouslySetInnerHTML` 渲染 ES 返回的高亮 HTML
- **URL 参数**：搜索关键词通过 URL query 参数 `q` 传递，支持浏览器前进/后退
- **每页数量**：`PAGE_SIZE = 20`
