# 智云星课 (NovaCloudEdu) - Web 端功能说明文档

> 本文档为智云星课 Web 端各页面的功能说明，配合截图展示系统全貌。

## 目录

### 用户端页面

| 页面 | 说明 |
|------|------|
| [首页](用户端-首页.md) | 平台门户，包含 Banner 轮播、搜索、课程推荐、学习统计等模块 |
| [课程中心](用户端-课程中心.md) | 课程浏览、筛选、搜索，课程详情与视频播放（含专注度检测） |
| [每日学习](用户端-每日学习.md) | 每日单词学习与每日美文阅读，支持 AI 问答互动 |
| [聊天与社交](用户端-聊天与社交.md) | 即时通讯、好友管理、群聊、音视频通话、AI 智慧体对话 |
| [电子书](用户端-电子书.md) | 电子书列表与在线阅读器，集成 AI 摘要/知识点/问答 |
| [学习圈](用户端-学习圈.md) | 社区圈子帖子浏览与发布编辑 |
| [AI 智能批改](用户端-AI智能批改.md) | 作业拍照上传、AI 流式批改、批改结果与学习画像 |
| [聚合搜索](用户端-聚合搜索.md) | 全站聚合搜索，覆盖书籍、章节、帖子等多类内容 |
| [公告列表](用户端-公告列表.md) | 平台公告浏览 |
| [用户反馈](用户端-用户反馈.md) | 用户意见反馈提交 |
| [页脚](用户端-页脚.md) | 全局页脚，包含导航链接、社交媒体入口与邮件订阅 |
