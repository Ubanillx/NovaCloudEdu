## 图13-2 AI域聚合根与值对象

```mermaid
classDiagram
    class AiAssistant {
        <<聚合根>>
        -AiAssistantId id
        -String name
        -String systemPrompt
        -String modelId
        -AiAssistantStatus status
        -UserId creatorId
        +bindKnowledgeBase(kbId)
        +bindWorkflow(workflowId)
    }
    
    class AiChatSession {
        <<聚合根>>
        -AiChatSessionId id
        -UserId userId
        -AiAssistantId assistantId
        -String title
        -String summary
        +addMessage(role, content)
        +generateSummary()
    }
    
    class KnowledgeBase {
        <<聚合根>>
        -KnowledgeBaseId id
        -String name
        -String description
        -UserId creatorId
        +addDocument(doc)
        +removeDocument(docId)
    }
    
    class Workflow {
        <<聚合根>>
        -WorkflowId id
        -String name
        -WorkflowDefinition definition
        -WorkflowStatus status
        -UserId creatorId
        +publish()
        +createVersion()
        +execute(input)
    }
    
    class McpServer {
        <<聚合根>>
        -McpServerId id
        -String name
        -String url
        -JsonNode config
        -Boolean enabled
        +enable()
        +disable()
        +testConnection()
    }

    AiAssistant "1" --> "*" KnowledgeBase : 绑定
    AiAssistant "1" --> "*" Workflow : 绑定技能
    AiChatSession "*" --> "1" AiAssistant : 所属
    Workflow --> McpServer : LLM节点引用
```

## 图13-3 批改域聚合设计

```mermaid
classDiagram
    class HomeworkSubmission {
        <<聚合根>>
        -HomeworkSubmissionId id
        -UserId userId
        -String title
        -GradingMode gradingMode
        -Subject subject
        -String grade
        -List~String~ imageUrls
        -String ocrText
        -Integer totalScore
        -Integer earnedScore
        -String aiComment
        -SubmissionStatus status
        +submitForGrading()
        +updateOcrResult(text)
        +completeGrading(score, comment)
    }

    class QuestionGrading {
        <<实体>>
        -Long id
        -Integer questionNumber
        -String questionText
        -String studentAnswer
        -String standardAnswer
        -Integer score
        -Judgment judgment
        -ErrorCategory errorCategory
        -List~String~ knowledgePoints
        -String analysis
    }

    class GradingMode {
        <<值对象>>
        EXAM_PAPER
        GENERAL
    }

    class ErrorCategory {
        <<值对象>>
        CALCULATION
        CONCEPT
        COMPREHENSION
        MEMORY
        METHOD
        CARELESS
    }

    HomeworkSubmission "1" --> "*" QuestionGrading
    HomeworkSubmission --> GradingMode
    QuestionGrading --> ErrorCategory
```
